# e-plantShopping

## Paradise Nursery Shopping Application

A React + Redux shopping cart application for an online houseplant store called **Paradise Nursery**.

### Features
- Landing page with company info and "Get Started" button
- Product listing page with 8+ plants grouped into 3 categories
- Shopping cart with quantity controls and delete buttons
- Redux Toolkit for global state management
- Dynamic cart badge in the navbar
- Responsive design with CSS

### Tech Stack
- React
- Redux Toolkit
- React Router
- Vite
- CSS
